# Laboratorio Crittografico: Cifrario Vigenère e Salto del Cavallo

Applicazione interattiva standalone per la sperimentazione e verifica computazionale dei metodi di decifratura:
- **Cifrario di Vigenère** (con **Tabula Recta 25×25**)
- **Salto del Cavallo** (Scacchiera 8×8 con percorsi geometrici)

## 🌐 Prova l'applicazione online
👉 **[Accedi al Laboratorio Crittografico Online](https://aromacomplesso.github.io/laboratorio-crittografico/)**

---

## 📖 Caratteristiche principali
1. **Cifrario di Vigenère**:
   - Alfabeto canonico a 25 caratteri (`ZABCDEFGHIJKLMNOPQRSTUVXY`, senza W, con Z=0).
   - Animazione visiva con mirino interattivo sulla Tabula Recta 25×25.
   - Sincronizzazione dinamica e allineamento orizzontale fisso delle lettere del testo e della chiave.
   - Funzione di pausa e ripresa dal passo corrente.

2. **Salto del Cavallo**:
   - Decifratura geometrica a scacchiera 8×8 (64 caselle).
   - Supporto per la Scacchiera 1 (Standard con partenza in f6) e la Scacchiera 2 (Speculare con partenza in f3).
   - Animazione interattiva passo-passo dei salti del cavallo (1 ➔ 64).
   - Layout affiancato ottimizzato per PC e dispositivi mobili.

3. **Trasferimento immediato**:
   - Possibilità di trasferire l'output decifrato da Vigenère direttamente alla scacchiera del Salto del Cavallo con un solo clic.

## 💻 Utilizzo in locale
Per eseguire il laboratorio in locale senza connessione a Internet:
1. Scarica o clona il repository:
   ```bash
   git clone https://github.com/aromacomplesso/laboratorio-crittografico.git
   ```
2. Fai doppio clic sul file `index.html` per aprirlo in qualsiasi browser moderno.
